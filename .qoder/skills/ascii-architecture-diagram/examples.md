## 实例 1：整项目（全景分层管道图，节选骨架）

产出结构：需求定位一段 ► 单代码块主图（7 层左右）► 每层可加 `[[xx详图]]` 占位。

```text
┌──────────────────────────────────────────────────────────────────────────┐
│                        【工程启动层】                                      │
│   pnpm dev ► Vite Dev Server (端口 3200 / 主机 0.0.0.0)                    │
│      ├── 加载 .env ──► 注入 import.meta.env                                │
│      └── /api 代理 ──────转发──────►  VITE_PROXY_TARGET (后端服务)          │
└──────────────────────────────┬───────────────────────────────────────────┘
                               │ 浏览器访问 http://localhost:3200
                               ▼
│ 【应用引导层】main.js                                                      │
│   bootstrap(): ①createApp ②setupStore ③setupDirectives                    │
│                ④setupRouter ⑤mount('#app') ⑥setupNaiveDiscreteApi        │
…（路由/入口控制层 → 布局渲染层 → 页面组件层 → 网络请求层 → 状态管理层 依次下推）
┌──────────────────────────────────────────────────────────────────────────┐
│                【状态管理层】 store/modules/ (Pinia)                        │
│   定位: 全系统唯一事实源; 边界: 只管"住"不管"运"; 单向数据流                   │
│   网络层 ──借凭证──► auth    守卫 ──查票──► auth.token                     │
│   auth.logout ──指挥清场──► user + permission + router + tab + 自身        │
```

要点：主图每层 3~6 行职责摘要；布局层等多选项在框内画并排子表格；用户要求加厚某层时，单独重写该框（详图卡片），其余层原样保留。

## 实例 3：单文件 / 双文件小文件夹（utils/storage/，向下钻到原生 API）

```text
【需求】 原生存储: 只认字符串 / 无命名空间 / 无过期机制
        本模块补齐: JSON序列化 + key前缀防撞名 + 过期时间戳 + 读时惰性清理

┌──────────────────────────────────────────────────────────────────────────┐
│                【实例装配层】 storage/index.js  (交付成品)                   │
│   const prefixKey = 'vue-naive-admin_'   ◄─ 全项目统一命名空间前缀          │
│   export lStorage = createLocalStorage({ prefixKey })  ► 长期存储          │
└──────────────────────────────┬───────────────────────────────────────────┘
                               │ createStorage(...) → new Storage(...)
                               ▼
┌──────────────────────────────┴───────────────────────────────────────────┐
│                【核心能力层】 storage/storage.js  (全部实现)                 │
│      ├ set(key, value, expire)      【写】                                 │
│      │    打包 { value, time, expire } ► JSON.stringify                    │
│      ├ getItem(key, def)            【读·核心判断在此】                     │
│      │      ├ expire为空 或 expire > now ──► 有效 ► 返回 { value, time }    │
│      │      ├ expire <= now ──► 已过期 ► remove(key) ► 返回 def (惰性清理)  │
│      │      └ 解析抛错 catch ──► remove(key) ► 返回 def (脏数据自愈)        │
└──────────────────────────────┬───────────────────────────────────────────┘
                               │ setItem / getItem / removeItem / clear
                               ▼
┌──────────────────────────────────────────────────────────────────────────┐
│                【原生介质层】 浏览器 window                                  │
│       localStorage (长期)              sessionStorage (会话)               │
└──────────────────────────────────────────────────────────────────────────┘
```

要点：单文件图必须钻到原生 API/构建配置为止，最后一层体现"谁兜底了谁"；图后跟"值得注意的设计点"编号段落。

## 增补实例（2026-10）：全边框模块五层图（真实产出节选，作模板套用）

来源：vue-naive-admin 的 store 与 http 模块图（.agents 版 skill 渲染器产出，已验证对齐）。
要点示范：表格账本、存活期三柜、分叉树、汇流线（┐│┤▼ 同列）、生命周期四链。

```text
┌────────────────────────────────────────────────────────────────────────────┐
│  第2层【六库一览】 store/modules/                                          │
│                                                                            │
│  库            存什么         谁来写           谁在读        存活期        │
│  ───────────────────────────────────────────────────────────────────────── │
│  auth.ts       accessToken    登录页/无感刷新  守卫查票      localStorage  │
│  user.ts       userInfo       守卫2 setUser    头像/昵称     内存,即丢     │
│  permission.ts 原粮/menus     守卫2 补录       侧栏渲染      内存,即丢     │
│                accessRoutes   setPermissions   按钮码消费                  │
│  app.ts        折叠/暗黑/布局 主题设置面板     换肤/SideMenu sessionStorage│
│  router.ts     不存数据!      —                auth/tab 跳转 寄存实例      │
│  tab.ts        tabs/activeTab 守卫2 addTab     标签栏/缓存   sessionStorage│
│                                                                            │
│  存活期三柜:  localStorage ──── auth          (磁盘, 刷新后唯一幸存者)     │
│               sessionStorage ─ app / tab     (关标签页归零)                │
│               内存, 无备份 ─── user/permission (守卫2补录分支存在的原因)   │
└────────────────────────────────────────────────────────────────────────────┘
```

```text
┌────────────────────────────────────────────────────────────────────────────┐
│  第3层【响应双路分诊】 interceptors.ts                                     │
│                                                                            │
│  成功路 resResolve(2xx 回来)                                               │
│    ├─ 非 JSON(文件流) ──> resolve 原始数据(逃生舱, 调用侧自理)             │
│    ├─ code ∈ [0,200] ──> resolve 剥壳 = ApiResult<T> ──> 调用方            │
│    └─ 其他 code ─────────────────────────┐                                 │
│  失败路 resReject(4xx/5xx/断网)          │                                 │
│    ├─ 无 response(断网 ERR_NETWORK) ─────┤                                 │
│    └─ HTTP 错误(有 response) ────────────┤                                 │
│                                          ▼                                 │
│     分诊 isAuthExpiredCode?  401 / 11007 / 11008                           │
│       ├─ 是 ──> 第4层 无感刷新(改道)                                       │
│       └─ 否 ──> resolveResError 归一 ──> reject 回调用方                   │
└────────────────────────────────────────────────────────────────────────────┘
```

要点：汇流线的 `┐│┤▼` 全部在同一显示列（本例第 42 列）——有中文的行禁止手数宽度，
交给 ZCode 版渲染器的 `text`+`at` 定位；表格列宽先列式预算（2+13+1+14+1+16+1+13+1+14=76）。
